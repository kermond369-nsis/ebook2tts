## 一、触发与门槛规则（硬性）

| 步骤 | 行为 |
|---|---|
| 1 | 用户在「在线朗读 → 密钥类型」中选择 **Token Plan** |
| 2 | **立即弹出**风险确认弹窗（模态，不可点外部关闭；仅「取消」或「同意」） |
| 3 | 弹窗正文**必须滑动到最底部**，底部「同意并继续」按钮才**由置灰转为可点**；未到底时按钮下方常驻提示：**"请滑动阅读至底部"** |
| 4 | 点「同意并继续」→ 记录 `tokenPlanAccepted=true`（本机）→ **Token Plan 密钥输入框解锁**，可填写 `tp-…` |
| 5 | 点「取消」→ **不切换**为 Token Plan（回退到「按量计费 API Key」或「在线关闭」），不记录同意 |
| 6 | 已同意过：可直接进入填写；但**每次进入设置页**在 Token Plan 选项旁常驻一行警示（可再次打开弹窗全文） |
| 7 | 密钥校验失败/被停用/被封禁时：展示平台方返回的原始错误信息，并**给出"改用按量计费 API Key"与"关闭在线"两条出路**（不得只报错、不得留死路） |

## 三、未达门槛时的表现（防呆）

- 「同意并继续」置灰不可点；点击无响应并抖动提示"请滑动阅读至底部"；
- 返回键/手势关闭 = 取消（不记录同意）；
- 不出现"已同意"字样直到真正滑到底；
- **绝不预勾选**、**绝不静默接受**。

## 四、验收（设备实测）

1. 选 Token Plan → 弹窗出现，三句白话在最顶部且字号最大；
2. 未滑到底 → 按钮置灰、文字提示存在；
3. 滑到底 → 按钮可点；勾选 + 同意 → 密钥框解锁，可输入 `tp-…`；
4. 取消 → 选项回退，`tokenPlanAccepted` 保持 false；
5. 重启 App 后：已同意者直接可填，未同意者仍需弹窗。
