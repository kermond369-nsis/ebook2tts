## 〇、一句话总览

本轮要回写的**行为变更**共 **9 项**（错误码、冷启就绪、MMKV 与 ABI、通知权限、备份边界、空间预检、无效权限、静态门、文档口径），其中 **3 项会改变用户/客户端可感知行为**（错误码、冷启首句、通知权限），**4 项属工程与合规**，**2 项属文档口径澄清**。

## 一、《需求书》v1.2 → **v1.3**

| 编号 | 类型 | 内容 | 来源 |
|---|---|---|---|
| **RQ-510** | 新增 | **通知权限（Android 13+）**：需要向用户展示下载进度/完成通知时，应先请求 `POST_NOTIFICATIONS`；**用户拒绝不得影响核心朗读功能**，并给出设置页引导 | BUG-P7-003（官方口径已核实） |
| **RQ-511** | 新增 | **数据备份边界**：应用数据备份（云备份/`adb backup`）**不得包含用户 API Key**；实现手段不限（排除规则或加密存储） | BUG-P7-002（ADR-011「Key 仅本机」的细化） |
| **RQ-512** | 新增 | **ABI 收敛**：正式包仅 **arm64-v8a**；`x86_64` 仅用于模拟器/调试链路；**不再支持 32 位（armeabi-v7a）** | 甲方 2026-09-16 指示 + MMKV 2.x 已无 32 位库（实测） |
| §5.1 修订 | 修订 | **引擎就绪口径细化**：「引擎就绪 ≤1.5 s」明确为「模型已安装前提下，`:tts_service` 冷启至后端可用」；**并新增硬性要求：冷启动后的首个合成请求不得因"后端未就绪"失败** | BUG-P7-011（实测 2.19 s 就绪、首句被拒） |
| §5.3 修订 | 修订 | 兼容性表述由「正式包 `arm64-v8a + armeabi-v7a`」改为「正式包 `arm64-v8a`」（与 RQ-512 一致） | 同上 |
| **DQ-2 修订** | 修订 | 决策记录 DQ-2（ABI 保留多架构）**改判**：正式包 arm64-v8a 单一 ABI；x86_64 仅测试包 | 甲方 2026-09-16 指示 |
| §5.2 修订 | 修订 | 稳定性「异常注入」清单扩充：**弱网/DNS 黑洞/极高延迟**（在线回落本地且不无声） | 计划 §四（agy SHOULD-2） |
| §6 验收总表 | 修订 | **TC-13 强化**：零模型场景客户端须收到平台 `ERROR_NOT_INSTALLED_YET(-9)`（原实现发 -12 无效值）；**新增 TC-16**（冷启动首请求成功）、**TC-17**（备份不含密钥）、**TC-18**（16 KB 页对齐合规）、**TC-19**（拒绝通知权限下功能可用） | BUG-P7-001/011/002/004/003 |

## 二、《架构书》v0.5 → **v0.6**

| 编号 | 类型 | 内容 | 来源 |
|---|---|---|---|
| §4.7 修订 | 修订 | **错误语义总表**追加硬约束：引擎回调 `SynthesisCallback.error()` **只允许使用平台常量** `android.speech.tts.TextToSpeech.ERROR_*`（`ERROR_SYNTHESIS=-3`、`ERROR_NOT_INSTALLED_YET=-9` …）；**禁止自造常量镜像**（原 `TextToSpeechErrors` 的 -4/-12 属实现错误） | BUG-P7-001（客户端实测收到 -4） |
| **ADR-015** | 新增 | **依赖与 ABI 策略**：① MMKV 升 **2.4.2**（官方 16 KB 页支持、64 位原生；已实测 API 兼容本仓用法）；② 放弃 `armeabi-v7a` 与 32 位（与 RQ-512 一致）；③ 16 KB 页对齐为**硬性验收项**（`readelf` 复核纳入构建检查）；④ 调试链路保留 `x86_64` | BUG-P7-004 + 甲方指示 + 实测 |
| §4.8 修订 | 新增条款 | **冷启动就绪等待与中止唤醒**：`READY_WAIT_MS` 预算须覆盖真实冷加载（当前 1500 ms 不足）；**且任何中止入口必须唤醒等待中的合成线程**（`requestStop()` → `signalReady()`），否则禁止提高预算；另增加**服务创建时异步预热**（让首个请求命中已就绪后端） | BUG-P7-011 + BUG-P7-013（agy 发现） |
| §4.3 修订 | 注记 | `PlaybackSynthesisCallback.done() was called before start()` 属 STOPPED 态**正常早退**（已观测），登记为观察项、不作为缺陷 | 实测（AOSP 语义） |
| §6.4/§6.5 修订 | 修订 | 空间预检口径：使用 `StorageManager.getAllocatableBytes()`（API 26+）而非 `File.usableSpace`；2.5× 预检公式不变 | BUG-P7-009 |
| §8.3 修订 | 修订 | 权限总表：**删除不存在的 `android.permission.BIND_TTS_SERVICE`**，改**自建 signature 级权限**（保留"仅系统连接可绑定"的现状语义；**禁止**裸删——裸删会对任意应用开放直接绑定并对在线额度构成盗用风险） | BUG-P7-010（双向论证） |
| §8.3 追加 | 新增 | **备份规则**：`dataExtractionRules`（Android 12+）＋ `fullBackupContent`（向下兼容）排除 MMKV 目录 | BUG-P7-002 |
| §6.5 / 依赖表 | 修订 | 依赖版本表更新（MMKV 2.4.2；其余按 P7-C 整理） | BUG-P7-007 |

## 三、《实现报告》v1.3 → **v1.4**

| 编号 | 类型 | 内容 | 对应缺陷 |
|---|---|---|---|
| **IM-523** | 新增 | 错误码对齐平台常量（删除 `TextToSpeechErrors` 自造常量）；单测固化数值断言；真机复核客户端收到 `-3/-9` | BUG-P7-001 |
| **IM-524** | 新增 | 冷启动就绪修复：**先**补 `requestStop() → signalReady()` 唤醒，**再**提高 `READY_WAIT_MS`（1500 → 3000~5000 ms），并在服务创建时异步预热模型；回归脚本（冷启 → 阅读器朗读 → 首句成功率） | BUG-P7-011 / 013 |
| **IM-525** | 新增 | 依赖与 ABI：MMKV `1.3.9 → 2.4.2`；`abiFilters` 收敛为 `arm64-v8a`（debug 保留 `x86_64`）；构建后 `readelf` 复核 16 KB 对齐 | BUG-P7-004 |
| **IM-526** | 新增 | `POST_NOTIFICATIONS` 请求链（Android 13+）+ 拒绝态引导；真机两态对照 | BUG-P7-003 |
| **IM-527** | 新增 | 备份排除密钥（`dataExtractionRules` + `fullBackupContent`） | BUG-P7-002 |
| **IM-528** | 新增 | 空间预检改用 `getAllocatableBytes()` | BUG-P7-009 |
| **IM-529** | 新增 | 自建 signature 权限替换无效声明 + 双向真机验证（系统连接可用 / 直接绑定被拒） | BUG-P7-010 |
| **IM-530** | 新增 | **静态门落地**：Android Lint（`:engine`/`:app`）+ detekt（1.23.8 CLI）报告基线化，**仅报告不阻断**；P3 清理批次分批消化 | BUG-P7-005/006/007/012 |
| §3.5 回填 | 回填 | 历史崩溃修复交叉引用：BUG-P7-008（`:tts_service` MMKV 未初始化）**已在 P3 批次修复并记档**（见《回写申请单-三件套升版-20260915》§三 IM 回填第①条）；本轮补"真机回归未复现"结论 | BUG-P7-008 |
| §4 修订 | 修订 | 测试与验收排期新增 **TC-16~19**，并登记"真机（Mi MIX 2S / SDM845 / Android 14）为性能调优目标机" | 甲方 2026-09-16 |
