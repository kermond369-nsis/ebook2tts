## 1. 背景与愿景

### 1.1 一句话
让**符合本地合成下限的机型**（**骁龙 8 Gen 1+／天玑 9300+**，见 RQ-519）也能**本地 AI 读书**——用户在习惯使用的阅读 App（阅读 / Legado 等）里直接选到本引擎来听书；**低于该下限的机型仍可正常使用在线合成**（在线路径不设算力下限）。

### 1.2 三原则
1. **全离线**：模型下载完成后零网络依赖（隐私：正文文本不出设备）；
2. **零成本**：无 API Key、无云服务、无账号；
3. **开放接入**：实现 Android 标准 TTS 引擎协议，任何支持"选择 TTS 引擎"的阅读 App 开箱可用。

### 1.3 分期路线（与 RQ 优先级对齐）
| 阶段 | 范围 |
|------|------|
| **M1（本期重构，0.2~0.3）** | 引擎稳定性重构（R-01~R-14）+ 流式管线 + **Flutter 配套 App（模型管理 / 音色库与试听[基础版] / 示例朗读 / 设置 / 诊断）** + 模型下载体系。对应 **P0 全部 + 核心 P1**（含 RQ-108 基础项） |
| **M2（0.4~0.6）** | 体验深化：试听矩阵增强（收藏/批量对比）、高级文本规范化（RQ-115）、轻量 NER（RQ-110）、音色命名表审定、性能矩阵实测冻结。对应 **次级 P1 + P2** |
| **M3（1.0）** | 打磨发布：商店化、真机矩阵、文档定稿、验收冻结 |
| 远期 | 本地 LLM 辅助分析（角色/情绪）、更多集成形态（架构保持可扩展） |

## 2. 范围定义

### 2.1 本期范围（In Scope）
- **引擎**：系统级 `TextToSpeechService`（必须原生，Flutter 只做 UI 层）；流式合成；收敛结论 R-01~R-14 全部处置；**移除**系统机械兜底模块（`SystemTtsBackend`）与相关配置项（DQ-3）；
- **进程契约**：引擎服务独立于 UI 生命周期（见 RQ-111）；
- **配套 App**：Flutter 全量重写（模型管理 / 音色库[基础试听] / 示例朗读 / 设置 / 诊断）；
- **平台**：Android 8.1+（minSdk **27**，targetSdk 34）；正式包 `arm64-v8a + armeabi-v7a`，测试包另附 `x86_64`（模拟器链路）；
- **模型**：**不内置**（首次使用引导下载）；Kokoro int8 主推（下载包约 147MB）+ VITS zh-ll 保底（约 119MB）；勘误记录见《勘误单-模型体积实测》。

### 2.2 非目标（Out of Scope）
- iOS / 桌面 / Web；
- 云端合成、账号体系、社交功能；
- 自研阅读器（阅读体验交由 Legado 等优秀项目）；
- **系统 TalkBack / 屏幕阅读器主力场景**：本引擎定位于小说/阅读类 App 长文本朗读，不针对无障碍实时朗读场景优化；产品内需明确提示，避免用户误设为全局无障碍语音（见 RQ-305/RQ-404）。

## 3. 用户与场景

| 用户 | 描述 |
|------|------|
| U1 小说听书用户 | 用 Legado 等 App 听书；关注多角色、长时间、锁屏 |
| U2 保底档用户 | 保底模型也能正常听（本地合成下限＝**骁龙 8 Gen 1+／天玑 9300+**，见 RQ-519）；低于下限者可走在线合成 |
| U3 折腾型用户 | 换模型 / 调线程 / 看日志 / 自己导模型 |

² **本表口径仅针对本地合成**：下限＝**骁龙 8 Gen 1+／天玑 9300+**（甲方 2026-09-21 口径，见 RQ-519）。**记号约定**：`骁龙 8 Gen 1+` ＝ **骁龙 8 Gen 1 及其之后发布的旗舰**（含 8+ Gen 1、8 Gen 2、8 Gen 3、8 Elite 系列等），**不是**指单一型号「8+ Gen 1」；`天玑 9300+` 同理（含 9400/9500 等后续旗舰）。文案书写时统一用「**骁龙 8 Gen 1 及以上**」，避免与「8+ Gen 1」混淆；**在线合成不设算力下限**（骁龙 425 级亦可正常调用）。**支持范围＝骁龙 8 Gen 1 及以上、天玑 9300 及以上，含此二者之后发布的旗舰芯片 —— 不逐型号指派**（甲方 2026-09-21 澄清）；「主流／高端」两行只是**性能预算的梯度参考**（越新的旗舰只会更优），**新增型号一律不得判为低配**（参 §10.3-4）。**原「保底＝天玑 1000／骁龙 765G 级」作废。**

- 包体：**单 ABI 包 ≤35MB；双 ABI 通用包 ≤60MB**（均不含模型；待实测校准）；
- 冷启动：引擎就绪 ≤1.5s（模型已安装）。

### 5.2 稳定性（可测量定义）
- **并发压测**：以 2 次/秒频率热更配置并持续合成 10 分钟 → 触发显式 GC 后，PSS 较基线增长 ≤10%、无持续单调增长趋势；LeakCanary/AddressSanitizer 无确定性泄漏报告；0 崩溃；
- 长稳：锁屏连续 2h 无 OOM、无断裂杂音；
- 异常注入：缺模型 / 坏包 / 断网 / 被系统杀——无崩溃、人话提示。

### 5.3 兼容性
- Android 8.1+（minSdk 27）；正式包 `arm64-v8a + armeabi-v7a`；
- targetSdk 34 合规（前台服务类型声明、通知权限等，见 RQ-201）。

### 5.4 隐私与合规
- 除模型下载外零网络；无遥测；第三方许可清单（sherpa-onnx / 模型 / Flutter 依赖）。

### 5.5 可维护性
- 核心纯函数（分句 / 角色分配 / 文本规范化 / 音色表）单测覆盖，CI 真跑；
- 文档驱动：三件套 + 编号互引（RQ→AR→IM）；改行为先改文档。
